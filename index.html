DreamDeck

DreamDeck ist ein privates, nicht kommerzielles Werkzeug zum Erstellen von KI-Bildern. Es wird ausschließlich vom Betreiber selbst genutzt und speichert die erzeugten Bilder im eigenen Google Drive des Betreibers.

DreamDeck is a private, non-commercial tool for creating AI images. It is used only by its owner and stores generated images in the owner's own Google Drive.

Datenschutz / Privacy

DreamDeck nutzt die Google-Drive-Schnittstelle nur mit der Berechtigung drive.file. Damit kann es ausschließlich Dateien sehen und ändern, die es selbst angelegt hat. Andere Dateien im Drive sind für DreamDeck nicht zugänglich.

Es werden keine Daten an Dritte weitergegeben, und es gibt keine Werbung, kein Tracking und keine Analyse. Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

Diese Seite wird über GitHub Pages bereitgestellt. GitHub kann dabei technische Zugriffsdaten (z. B. IP-Adressen) verarbeiten, siehe die Datenschutzerklärung von GitHub.

DreamDeck only uses the drive.file scope and can access only files it created itself. No data is shared with third parties; no ads, tracking or analytics. Access can be revoked at any time at myaccount.google.com/permissions.
